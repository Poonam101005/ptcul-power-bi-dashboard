# PTCUL Energy Performance Dashboard (Power BI)

Interactive Power BI dashboard built on a sample dataset of 240 monthly records across 20 substations (Jan–Dec 2025).

**Note:** This is a sample dataset created for a portfolio project. It is not official PTCUL performance data.

## Key figures
- Energy transmitted: 46.01M MWh
- Transmission loss: 2.16%
- Revenue: 9.66K Cr
- Estimated loss value: 212.83 Cr (recalculated with a DAX measure, not the source column)
